## 1. 인증 시스템

### TC-1.1 회원가입
| 단계 | 테스트 내용 | 예상 결과 |
|------|-----------|----------|
| 1 | `/register` 접속 | 회원가입 폼 표시 |
| 2 | 이름/이메일/연락처/비밀번호 입력 | 자동 하이픈 포맷팅 (연락처) |
| 3 | 비밀번호 6자 입력 후 제출 | "8자 이상" 에러 메시지 |
| 4 | 비밀번호 불일치 입력 후 제출 | "일치하지 않습니다" 에러 |
| 5 | 약관 미동의 상태에서 제출 | 버튼 비활성화 |
| 6 | 이용약관/개인정보처리방침 클릭 | 새 탭에서 `/terms`, `/privacy` 열림 |
| 7 | 정상 입력 후 제출 | "이메일 인증 메일 발송" 성공 화면 |

### TC-1.2 로그인
| 단계 | 테스트 내용 | 예상 결과 |
|------|-----------|----------|
| 1 | `/login` 접속 | 로그인 폼 표시 |
| 2 | 잘못된 비밀번호 입력 | "이메일 또는 비밀번호가 올바르지 않습니다" |
| 3 | 관리자 계정으로 로그인 | `/mypage`로 리다이렉트 |
| 4 | 헤더 확인 | "로그인/회원가입" → "관리자님" + 드롭다운 |
| 5 | 드롭다운에서 "관리자" 클릭 | `/admin` 이동 |

### TC-1.3 비밀번호 재설정
| 단계 | 테스트 내용 | 예상 결과 |
|------|-----------|----------|
| 1 | 로그인 페이지에서 "비밀번호를 잊으셨나요?" 클릭 | `/forgot-password` 이동 |
| 2 | 이메일 입력 후 "재설정 링크 발송" | 이메일 발송 확인 화면 |

### TC-1.4 보호 라우트
| 단계 | 테스트 내용 | 예상 결과 |
|------|-----------|----------|
| 1 | 비로그인 상태에서 `/mypage` 접속 | `/login?redirect=/mypage` 리다이렉트 |
| 2 | 비로그인 상태에서 `/admin` 접속 | `/login?redirect=/admin` 리다이렉트 |
| 3 | 일반 회원으로 `/admin` 접속 | `/mypage` 리다이렉트 |

### TC-1.5 로그아웃
| 단계 | 테스트 내용 | 예상 결과 |
|------|-----------|----------|
| 1 | 헤더 사용자명 클릭 → "로그아웃" | 홈으로 리다이렉트, 헤더 "로그인/회원가입" 복구 |

## 2. 교육프로그램 관리

### TC-2.1 프로그램 등록 (Admin → 공개)
| 단계 | 테스트 내용 | 예상 결과 |
|------|-----------|----------|
| 1 | `/admin/programs` 접속 | 프로그램 목록 표시 |
| 2 | "프로그램 등록" 클릭 | `/admin/programs/new` 폼 |
| 3 | 프로그램명 입력, 카테고리 선택, 유형 선택 | 정상 입력 |
| 4 | 썸네일 이미지 업로드 | 이미지 미리보기 표시 |
| 5 | "등록" 클릭 | 프로그램 목록으로 리다이렉트 |
| 6 | `/programs` 접속 | 새 프로그램 카드 표시 (status가 draft면 안 보임) |
| 7 | `/admin/programs/[id]`에서 상태를 "공개"로 변경 + 저장 | 저장 성공 메시지 |
| 8 | `/programs` 새로고침 | 공개된 프로그램 카드 표시 |

### TC-2.2 프로그램 수정 (Admin → 공개)
| 단계 | 테스트 내용 | 예상 결과 |
|------|-----------|----------|
| 1 | `/admin/programs`에서 편집 아이콘 클릭 | 수정 페이지 이동 |
| 2 | 제목 수정 + 썸네일 변경 + "추천 프로그램" 체크 | 정상 입력 |
| 3 | "저장" 클릭 | "프로그램이 저장되었습니다" 메시지 |
| 4 | `/programs/[slug]` 접속 | 수정된 제목 반영 확인 |
| 5 | 홈페이지 `/` 확인 | 추천 교육 섹션에 표시 확인 |

### TC-2.3 프로그램 삭제
| 단계 | 테스트 내용 | 예상 결과 |
|------|-----------|----------|
| 1 | 수정 페이지에서 "삭제" 클릭 | confirm 다이얼로그 |
| 2 | "확인" 클릭 | 목록으로 리다이렉트, 삭제 확인 |
| 3 | `/programs` 확인 | 삭제된 프로그램 안 보임 |

### TC-2.4 프로그램 상세 페이지 확인
| 단계 | 테스트 내용 | 예상 결과 |
|------|-----------|----------|
| 1 | `/programs/[slug]` 접속 | 프로그램 상세 정보 표시 |
| 2 | 썸네일 이미지 | 등록한 이미지 표시 |
| 3 | 커리큘럼 섹션 | 모듈별 커리큘럼 표시 |
| 4 | 기대효과 섹션 | 학습 성과 표시 |
| 5 | "교육 문의하기" 버튼 클릭 | `/inquiry` 이동 |

### TC-2.5 프로그램 검색/필터
| 단계 | 테스트 내용 | 예상 결과 |
|------|-----------|----------|
| 1 | `/programs` 검색창에 "AI" 입력 | AI 관련 프로그램만 필터링 |
| 2 | "AI·에듀테크 교육" 카테고리 탭 클릭 | 해당 카테고리만 표시 |
| 3 | "전체" 탭 클릭 | 모든 프로그램 표시 |
