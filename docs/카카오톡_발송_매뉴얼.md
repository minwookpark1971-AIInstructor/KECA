# 카카오톡 발송 매뉴얼 (관리자용)

## 사전 준비

카카오톡 발송을 위해 다음이 완료되어야 합니다:

1. **솔라피 계정** 생성 및 API Key/Secret 발급
2. **카카오 비즈니스 채널** 개설 및 솔라피에서 채널 연동 (PFID 발급)
3. **Vercel 환경변수** 3개 등록: `SOLAPI_API_KEY`, `SOLAPI_API_SECRET`, `SOLAPI_PFID`
4. **알림톡 사용 시**: 솔라피에서 템플릿 등록 후 카카오 검수 승인 필요

---

## 1. 수신자 선택

1. 관리자 페이지 좌측 메뉴에서 **회원관리**를 클릭합니다.
2. 상단 필터(전체/승인대기/정회원/강사 등)와 검색창으로 대상 회원을 찾습니다.
3. 발송할 회원의 **체크박스**를 선택합니다. (상단 체크박스로 전체 선택 가능)
4. 화면 하단에 나타나는 액션바에서 **카카오톡 발송** 버튼을 클릭합니다.
5. 자동으로 카카오톡 발송 페이지로 이동합니다.

> 연락처(전화번호)가 등록되지 않은 회원은 자동으로 발송 대상에서 제외됩니다.

---

## 2. 발송 유형 선택

카카오톡 발송 페이지 상단에서 발송 유형을 선택합니다:

| 구분 | 알림톡 | 브랜드 메시지 |
|------|--------|---------------|
| 용도 | 정보성 메시지 (교육 일정, 결제 확인 등) | 광고/홍보 메시지 |
| 형식 | 카카오 검수 승인 템플릿 기반 | 자유 형식 |
| 수신 동의 | 불필요 | 필수 (미동의 회원 자동 제외) |
| 야간 발송 | 가능 | 불가 (21:00~08:00) |
| 이미지 첨부 | 불가 | 가능 |

---

## 3. 메시지 작성

### 3-1. 템플릿 사용 (선택사항)

- 등록된 카카오 템플릿이 있으면 드롭다운에서 선택할 수 있습니다.
- 템플릿을 선택하면 본문이 자동으로 채워집니다.
- "직접 작성"을 선택하면 빈 상태에서 시작합니다.

### 3-2. 본문 작성

메시지 본문에 다음 **변수**를 사용할 수 있습니다:
- `#{이름}` : 수신자 이름으로 자동 치환
- `#{연락처}` : 수신자 전화번호로 자동 치환

**알림톡 예시:**
```
[KECA] #{이름}님, 교육 일정 안내

교육명: OO 과정
일시: 2026-00-00 10:00
장소: OOO

자세한 내용은 홈페이지를 확인해주세요.
```

**브랜드 메시지 예시:**
```
[KECA] 신규 교육 프로그램 안내

안녕하세요, #{이름}님!
KECA에서 새로운 교육 프로그램을 준비했습니다.

자세한 내용 확인하기 >
```

### 3-3. 링크 버튼 추가 (최대 5개)

1. **링크 버튼 추가** 버튼을 클릭합니다.
2. **버튼 이름** 입력 (예: "자세히 보기")
3. **URL** 입력 (예: https://keca.vercel.app/lectures)
4. **유형** 선택: 일반 / 동영상 / 블로그
5. **추가** 버튼을 클릭합니다.

> URL을 입력하면 미리보기(OG 메타데이터)가 자동으로 표시됩니다.

### 3-4. 이미지 첨부 (브랜드 메시지만)

- 브랜드 메시지 선택 시 이미지 첨부 영역이 나타납니다.
- **이미지 선택** 버튼을 클릭하여 JPG/PNG 파일을 업로드합니다.
- 권장 크기: 800 x 400px

---

## 4. 발송 정보 확인

우측 패널에서 발송 정보를 확인합니다:

- **전체 수신자**: 선택한 총 회원 수
- **연락처 보유**: 전화번호가 등록된 회원 수
- **발송 대상**: 실제 발송될 회원 수
- **링크 버튼**: 추가한 버튼 수
- **이미지**: 첨부 여부

---

## 5. 발송

### 일반 발송

1. **카카오톡 발송** 버튼을 클릭합니다.
2. "OO명에게 카카오톡 메시지를 발송하시겠습니까?" 확인 팝업이 표시됩니다.
3. **확인**을 클릭하면 발송이 시작됩니다.
4. 발송 완료 후 성공/실패 건수가 표시됩니다.

### 테스트 발송

실제 발송 전에 내 번호로 먼저 확인할 수 있습니다:

1. **테스트 발송 (1건)** 버튼을 클릭합니다.
2. 수신할 전화번호를 입력합니다. (예: 010-1234-5678)
3. 해당 번호로 1건만 즉시 발송됩니다.

> 테스트 발송은 캠페인 기록에 남지 않습니다.

---

## 6. 발송 결과 확인

- 발송 이력은 **마케팅 > 발송 이력** 메뉴에서 확인할 수 있습니다.
- 각 캠페인별 성공/실패 건수, 발송 일시가 표시됩니다.
- 솔라피 Webhook을 통해 수신 확인(delivered), 읽음(opened) 상태가 자동 업데이트됩니다.

---

## 7. 템플릿 관리

### 솔라피 템플릿 동기화

1. **마케팅 > 템플릿 관리** 메뉴로 이동합니다.
2. **솔라피 동기화** 버튼을 클릭합니다.
3. 솔라피에 등록된 알림톡 템플릿이 자동으로 가져와집니다.
4. 검수 상태(초안/검수중/승인됨/반려됨)가 함께 표시됩니다.

### 수동 템플릿 생성

1. **새 템플릿** 버튼을 클릭합니다.
2. 이름, 채널(카카오톡), 유형(알림톡/브랜드 메시지)을 선택합니다.
3. 알림톡의 경우 **카카오 템플릿 코드**를 입력합니다.
4. 본문을 작성하고 **저장**합니다.

---

## 주의사항

- **알림톡**은 계약/거래에 직접 관련된 정보만 허용됩니다. 광고 문구가 포함되면 카카오 검수에서 반려됩니다.
- **브랜드 메시지**는 카카오톡 채널 친구이며 수신 동의한 회원에게만 발송됩니다.
- 야간 시간대(21:00~08:00)에는 브랜드 메시지를 발송할 수 없습니다.
- 솔라피 API 키가 설정되지 않은 상태에서는 발송이 스킵됩니다.
